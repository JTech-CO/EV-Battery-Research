**ID:** `BATTERY_ML` · **우선순위:** P3 · **유형:** `software_reference_resource`

## 확인한 범위
배터리 데이터 처리·벤치마크를 다루는 연구 프레임워크이다.

## 권장 활용
추후 같은 셀 홀드아웃으로 데이터 기반 기준 모델을 비교한다.

머신러닝 기준 모델의 비교 후보이다. 물리 데이터 수집과 권리 검토를 대신하지 않으며 이번 ZIP에는 학습·추론 코드를 넣지 않는다.

## 금지할 일반화
다중 물리 물성 DB나 원본 데이터 재배포 허가를 대신하지 않는다.

## 수집·권리 상태
상태: `metadata_only`. 권리: `reference_only;dataset_licenses_separate`. 원본 바이트 파일 다운로드: **미완료**. 내용 스냅샷은 별도 provenance를 확인하며 원본 바이트와 동일하다고 주장하지 않는다.

## 다음 수집 작업
ML 연구가 별도로 승인될 때 원 논문·공식 코드·개별 데이터의 권리를 검토한다.
