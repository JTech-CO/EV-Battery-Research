# Iowa State ILCC cycling dataset

[English](../en/ISU_ILCC.md) | [카탈로그](../../resources.json)

**ID:** `ISU_ILCC` · **우선순위:** P1 · **유형:** `experimental_dataset`

## 확인한 범위
아카이브 설명은 NMC/흑연 파우치 238개, 63개 조건, 30°C이다. 파일 수와 대조하지는 못했다.

## 권장 활용
조건 상호작용과 개체 분산을 셀 단위 분할로 분석한다.

조건 조합과 개체 차이를 분석할 후보이다. 기록된 238개 셀·63개 조건은 아카이브 설명 기준이며 다운로드한 파일 수가 아니다.

## 금지할 일반화
한 온도 범위로 광범위한 Arrhenius 의존성을 식별하지 않는다.

## 수집·권리 상태
상태: `metadata_only_primary_blocked`. 권리: `not_reverified`. 원본 바이트 파일 다운로드: **미완료**. 내용 스냅샷은 별도 provenance를 확인하며 원본 바이트와 동일하다고 주장하지 않는다.
