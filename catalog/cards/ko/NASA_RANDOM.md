# NASA randomized battery usage

[English](../en/NASA_RANDOM.md) | [카탈로그](../../resources.json)

**ID:** `NASA_RANDOM` · **우선순위:** P1 · **유형:** `experimental_dataset`

## 확인한 범위
랜덤 부하·온도 사용과 기준 특성화가 포함된 별도 아카이브이다.

## 권장 활용
불규칙 이력에서 상태 추정·열화를 검증하고 기준 점검을 동일 조건에서 비교한다.

불규칙한 부하 이력과 기준 성능 평가를 구분하는 검증에 적합하다. 랜덤 부하는 실제 차량 운행 기록과 다르다.

## 금지할 일반화
실험실 랜덤 전류를 실제 차량 운행 이력이라고 표시하지 않는다.

## 수집·권리 상태
상태: `metadata_only`. 권리: `per_dataset_review`. 원본 바이트 파일 다운로드: **미완료**. 내용 스냅샷은 별도 provenance를 확인하며 원본 바이트와 동일하다고 주장하지 않는다.
