# Materials Project material calculations

[English](../en/MATERIALS_PROJECT.md) | [카탈로그](../../resources.json)

**ID:** `MATERIALS_PROJECT` · **우선순위:** P3 · **유형:** `computed_materials_resource`

## 확인한 범위
공식 API로 접근하는 결정·전자·열역학 계산 자료이다.

## 권장 활용
추후 다중 스케일 소재 연구의 상·열역학 사전 정보로 제한한다.

원자·결정 수준의 계산 자료는 소재 연구의 사전 정보이다. 실제 제조된 셀의 유효 물성이나 사이클 수명을 대신하지 않는다.

## 금지할 일반화
제조 셀의 유효 확산·교환 전류·다공 구조·열화 거동을 직접 대체하지 않는다.

## 수집·권리 상태
상태: `metadata_only`. 권리: `API_terms_review`. 원본 바이트 파일 다운로드: **미완료**. 내용 스냅샷은 별도 provenance를 확인하며 원본 바이트와 동일하다고 주장하지 않는다.

## 다음 수집 작업
API 요구사항·약관을 검토하고 환경변수 인증과 제한된 쿼리를 사용한다. API 키·결과는 동봉하지 않았다.
