# BLAST-Lite model resources

[English](../en/BLAST_LITE.md) | [카탈로그](../../resources.json)

**ID:** `BLAST_LITE` · **우선순위:** P2 · **유형:** `software_model_resource`

## 확인한 범위
화학계별 반경험적 수명 모델 계수·예제와 관련 도구군이다.

## 권장 활용
모델 계열의 비교 기준·사전 정보로 사용하고 원래 학습 영역을 보존한다.

반경험적 열화 모델의 비교 기준이지 실험 정답 데이터가 아니다. 원시 관측과 모델이 생성한 결과를 같은 데이터 범주에 넣지 않는다.

## 금지할 일반화
예측 수명을 독립적인 실험 정답으로 사용하지 않는다.

## 수집·권리 상태
상태: `metadata_only`. 권리: `inspect_upstream_code_and_data_licenses`. 원본 바이트 파일 다운로드: **미완료**. 내용 스냅샷은 별도 provenance를 확인하며 원본 바이트와 동일하다고 주장하지 않는다.

## 다음 수집 작업
공식 연결 저장소의 릴리스와 계수 출처·라이선스를 고정한다. 이번 연구 단계에서는 설치·시뮬레이션하지 않는다.
