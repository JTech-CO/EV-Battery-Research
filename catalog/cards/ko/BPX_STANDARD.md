# Battery Parameter eXchange

[English](../en/BPX_STANDARD.md) | [카탈로그](../../resources.json)

**ID:** `BPX_STANDARD` · **우선순위:** P0 · **유형:** `interchange_standard_resource`

## 확인한 범위
공개 1.1 안내는 SPMe·히스테리시스·복합 전극·LAM/LLI·셀 상태를 설명한다. 동봉 예제는 0.1이다.

## 권장 활용
원본 단위·의미를 보존하는 명시적 마이그레이션과 의미 검사를 설계한다.

교환 형식의 기준이다. 동봉 파일은 BPX 0.1이므로 현재 규격처럼 표시하지 않고 단위·반응식 정의를 확인하는 마이그레이션 대상으로 남겼다.

## 금지할 일반화
헤더 변경을 마이그레이션으로 여기거나 팩·열화 속도·불확실성이 자동 지정됐다고 하지 않는다.

## 수집·권리 상태
상태: `metadata_only`. 권리: `public_notes;full_docs_form_gated`. 원본 바이트 파일 다운로드: **미완료**. 내용 스냅샷은 별도 provenance를 확인하며 원본 바이트와 동일하다고 주장하지 않는다.

## 다음 수집 작업
현재 공식 규격·스키마를 확인한다. 연락처 폼은 미제출이며 1.1 적합성을 주장하지 않는다.
