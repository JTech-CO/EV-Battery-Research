# Battery Microstructures Library

[English](../en/NLR_MICRO.md) | [카탈로그](../../resources.json)

**ID:** `NLR_MICRO` · **우선순위:** P2 · **유형:** `experimental_and_reconstructed_dataset`

## 확인한 범위
NMC·흑연 전극의 회색·분할 3D 구조이며 탄소·바인더 영역은 수치 재구성을 포함한다.

## 권장 활용
복셀·분할 불확실성을 포함해 형상 지표와 수송 사전 정보를 얻는다.

CT 기반 구조를 얻을 수 있으나 탄소·바인더 영역 일부는 수치적으로 생성된 것이다. 계측 구조와 재구성 구조를 분리해야 한다.

## 금지할 일반화
모든 상이 실험에서 직접 영상화됐다고 하지 않는다.

## 수집·권리 상태
상태: `metadata_only`. 권리: `custom_agreement_not_accepted`. 원본 바이트 파일 다운로드: **미완료**. 내용 스냅샷은 별도 provenance를 확인하며 원본 바이트와 동일하다고 주장하지 않는다.

## 다음 수집 작업
사용자가 이용 조건을 직접 검토·동의한 뒤 복셀·상 라벨·캘린더링·재구성 방법을 기록한다.
